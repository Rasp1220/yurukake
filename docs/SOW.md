# Webアプリ開発 SOW（作業範囲定義書）

## 1. プロジェクト概要
### 1.1 プロジェクト名
お出かけSNSキュレーション＆スマート案内アプリ（仮称：`StrollSync`）

### 1.2 プロジェクトの目的
InstagramやYouTubeなどのSNS上にある「行ってみたいスポット情報」をスムーズに収集・一元管理し、効率的なお出かけルートの作成までをシームレスに行えるWebアプリケーションを構築する。これにより、お出かけ前の情報収集や計画のストレスを軽減する。

---

## 2. 対象ユーザー
* 休日のデートや友達との遊びの計画を立てるのが好きな人
* SNS（Instagram, YouTube）でよくお店や観光地を調べるが、情報の管理やルート決めに手間取っている人
* 「ここ行きたい！」と思ったスポットを効率よく回りたい人

---

## 3. システム機能要件（スコープ）

本アプリの機能を、初期リリース向けの「フェーズ1（MVP）」と、将来的な「フェーズ2」に分割して定義する。

### フェーズ1：最小限の実装（MVP）
まずはコア体験となる「SNS動画の検索からマップ登録・ルート化」までをゴールとする。

| ID | 機能名 | 概要 | 優先度 |
| :--- | :--- | :--- | :--- |
| F-01 | **スポット・キーワード検索** | 任意のエリア名やジャンル（例：「浅草 カフェ」）で検索できる。 | 高 |
| F-02 | **SNS動画・情報連携** | YouTube Data APIを使用し、検索キーワードに関連するおすすめVlogやスポット紹介動画を一覧表示する。 | 高 |
| F-03 | **ワンタップ「行きたいリスト」追加** | 気に入ったスポットや動画を、自分のマイリスト（保存ボックス）にワンタップで保存できる。 | 高 |
| F-04 | **マイマップ一括表示** | 保存したスポットを、Google Maps上でまとめてピン留め表示する。 | 高 |
| F-05 | **シンプルルート案内** | リスト内のスポット間を結ぶ移動ルートや所要時間をGoogle Maps API経由で確認できる。 | 中 |

### フェーズ2：拡張機能（将来的なスコープ）
* **Instagram連携／URLインポート:** SNSのリンクを貼るだけで自動解析する機能
* **動画タイムスタンプ連動:** 動画のどの秒数でそのスポットが紹介されていたかジャンプする機能
* **ルート自動最適化:** 複数のスポットを効率よく回る順序に自動並び替えする機能
* **リアルタイム情報:** 営業中かどうかのステータス表示

---

## 4. 画面・UXフロー
1. **ホーム画面:** 検索バーがあり、行きたいエリアやジャンルを入力する。
2. **検索結果画面:** YouTubeなどの関連動画・スポット情報カードがタイル状に並ぶ。
3. **詳細・保存モーダル:** 動画を視聴しつつ、「行きたいリストに追加」ボタンを押す。
4. **マイページ（マップ＆リスト）:** 保存した場所の一覧と、それらがプロットされたGoogleマップが確認でき、お出かけ当日のしおりとして活用できる。

---

## 5. 推奨技術スタック
開発コストとパフォーマンスを考慮した推奨構成。

* **フロントエンド:** Next.js (React) または Vue.js（UI構築・マップ描画）
* **バックエンド:** Node.js (Express) または Python (FastAPI) （API連携・データ処理）
* **データベース:** PostgreSQL または Firebase (Firestore) （ユーザーデータ・保存リストの管理）
* **外部API:**
    * YouTube Data API v3（動画検索）
    * Google Maps Platform (Maps JavaScript API / Directions API)（地図・ルート表示）
