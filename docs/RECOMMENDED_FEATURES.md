# おすすめ追加機能一覧

`yurukake`（StrollSync）フェーズ1（MVP）の実装を踏まえ、次フェーズ以降で検討すべき追加機能の提案をまとめる。

> 1〜5は実装済み（README.mdの「追加機能」を参照）。機能5は、店舗・施設APIとの連携ではなく、Google Map・YouTube公式アプリへのシンプルなディープリンクとして実装。

## 1. 詳細な絞り込みフィルター（ジャンル・エリア拡大）

- キーワード検索に加え、「カフェ」「絶景」「グルメ」「子連れ」などのジャンルタグや、東京・大阪・北海道以外のエリア追加・詳細指定を入れる。
- ユーザーがその時の気分やシチュエーションに合った動画を見つけやすくなる。

## 2. お出かけプラン・スケジュール作成機能

- マイページの「行きたいリスト」に入れた動画を並び替え、「1日目」「2日目」のようなタイムスケジュールに組み込める機能。
- 単なる「ブックマーク」から「実際の旅行のしおり」へと進化し、サイトの滞在時間が大幅に伸びる。

## 3. おすすめ（レコメンド）機能

- マイページに登録されたジャンルや、過去に検索したキーワードの傾向を分析し、「あなたにおすすめの動画」をトップページやマイページに表示する。
- ユーザーがまだ知らない魅力的なお出かけスポットとの出会いを提供できる。

## 4. ソーシャルシェア（SNS共有）機能

- 作成した「行きたいリスト」や「お出かけプラン」を、XやLINEなどで簡単にシェアできるボタンを設置する。
- 友人や恋人とのお出かけの相談がスムーズになり、サイト自体の宣伝効果も期待できる。

## 5. 現地での利便性向上（外部アプリへの導線強化）

- 動画の詳細画面に「YouTube公式アプリで見る」へのダイレクトリンクや、周辺の店舗・施設情報を確認できる導線を配置する。
- 実際に外出して現地にいる時でも、実用的なツールとして使いやすくなる。
